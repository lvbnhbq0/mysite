**Format:** independent study on an external online platform (Stepik), focused on practical administration and efficient work in a Linux environment.

### Topics

- **Terminal fundamentals:** navigating the filesystem, managing processes and packages, working with archivers (gzip, zip, tar) and search utilities (find, grep).
- **Remote systems:** SSH setup, copying data with scp, FileZilla, and long-running sessions with the tmux terminal multiplexer.
- **Automation:** Bash scripting (conditionals, loops, functions, arguments), plus text-stream processing with sed and regular expressions.

### Outcomes

- Completed all graded and interactive blocks, including tasks that required handling non-standard situations.
- Compiled a detailed report with visual proof (screenshots of completed steps), published on GitHub and attached as a PDF on this page.
- The skills support independent server administration, debugging data pipelines, and reproducing research environments for future coursework and applied projects.
